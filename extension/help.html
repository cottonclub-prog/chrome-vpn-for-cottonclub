CottonClub — Hysteria 2

Установка без администратора

Скачайте проект с GitHub (Code → Download ZIP), полностью распакуйте и запустите Install.cmd обычным двойным щелчком. Загрузчик скачает и проверит готовый комплект. Также можно скачать установочный ZIP из Releases. Python не нужен.

  1. Откройте chrome://extensions и включите режим разработчика.
  2. Нажмите «Загрузить распакованное расширение» и выберите %LOCALAPPDATA%\Chrome VPN for CottonClub\extension. Установщик покажет полный путь.
  3. Закрепите значок CottonClub. Ярлык «CottonClub Hysteria 2» повторно открывает страницу настройки и папку расширения.

Установка, обновление и удаление работают только для текущего пользователя Windows, без UAC. Program Files и общесистемная регистрация не изменяются. Старую системную версию отключите; при смене пути расширения заранее сохраните ссылку подписки.

Подключение

  1. Вставьте HTTPS-подписку, ссылку hysteria2:// / hy2:// или Base64-список и нажмите «Загрузить».
  2. Выберите сервер и маршрутизацию, нажмите «Подключить», дождитесь статуса подключения и IP VPN.
  3. Для завершения нажмите «Отключить VPN». Перед сменой сервера или режима отключитесь.

Поддерживается исключительно Hysteria 2. В смешанных подписках другие протоколы пропускаются. Для Hysteria 2 необходим доступ по UDP к серверу.

VPN действует только в обычных окнах профиля Chrome. По умолчанию Россия и локальная сеть доступны напрямую; можно выбрать «Всё через VPN». Инкогнито и другие приложения не охватываются.

После перезапуска браузера подключитесь заново. При остановке помощника прокси остаётся включённым. Переподключитесь или нажмите «Отключить VPN».

Данные

Подписка сохраняется локально в Chrome без дополнительного шифрования приложения. Общий идентификатор устройства: %LOCALAPPDATA%\ZXC-Desktop\device-id.txt. Проверка IP обращается к api.ipify.org через VPN.

Обновление и удаление

Нажмите «Проверить обновления», затем «Обновить — VPN отключится». Дождитесь завершения установки и нажмите «Перезагрузить расширение». Администратор не требуется.

Для удаления отключите VPN, удалите расширение в Chrome и запустите %LOCALAPPDATA%\Chrome VPN for CottonClub\Uninstall.cmd. Системная установка старой версии не затрагивается.

Ошибки

«Помощник недоступен» — повторите установку и проверьте путь расширения. «Лимит устройств» — проверьте подписку в панели. Если Hysteria 2 нет в подписке, запросите её у поставщика. Корпоративные политики и антивирус могут блокировать установку; отсутствие запроса администратора не отменяет эти ограничения.
