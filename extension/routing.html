Правила маршрутизации

Правила проверяются сверху вниз. Первое совпадение выбирает маршрут. Всё, что не совпало, идёт через VPN.

Исходные правила: IP России, .ru, .su и .рф — напрямую. Списка отдельных российских доменов нет.

Список пуст — весь трафик будет идти через VPN.

Домен — например, example.com, .ru или printer.local. Правило включает поддомены. Без https://, пути и порта.

IP / подсеть — например, 192.168.1.10, 192.168.0.0/16 или fc00::/7. Применяется, когда сайт открыт по IP. Домены предварительно не разрешаются для поиска совпадения с IP.

IP России — встроенные публичные российские диапазоны. Можно отключить, удалить или выбрать для них VPN. Локальные адреса не входят в эту группу; добавьте их отдельно при необходимости.

Исключение ставьте выше общего правила: например, example.ru → VPN выше .ru → Напрямую.

Загрузка…

Перед сохранением отключите VPN. После сохранения подключитесь в режиме «По правилам». В режиме «Всё через VPN» этот список не применяется. Правила хранятся только в данном профиле Chrome.
