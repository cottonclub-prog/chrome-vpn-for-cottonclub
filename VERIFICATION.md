# Проверка копии Chrome VPN for CottonClub — 28 сентября 2026

- Собран `dist/Chrome-vpn-for-cottonclub-Windows-x64.zip`, около 48 МиБ. Использованы имеющиеся ядра Xray/sing-box из исходного проекта (`-SkipDownload`), новая загрузка ядер не проверялась.
- В исходной версии прошёл 21 Python-тест: импорт подписок, Native Messaging, конфигурация Reality, проверка SOCKS5, занятый порт, завершение процессов, реальные локальные соединения VLESS через Xray и Hysteria 2 через sing-box. Код помощника и готовый EXE перенесены без изменений; сетевые тесты для переименования повторно не выполнялись.
- 4 JavaScript-теста: сохранение блокирующего прокси, отключение, восстановление очереди команд, выбранный сервер. Chrome API в этих тестах имитируется.
- Проверен синтаксис PowerShell-установщика, удаления, сборки и запуска, а также обоих JavaScript-файлов.
- Проверены CRC архива и SHA-256 всех файлов; режим `Install.ps1 -VerifyOnly` принимает целый комплект и отклоняет повреждённый без повышения прав.
- Готовый `ZXC-AdminHost.exe` обработал framed JSON-команды status/load/disconnect, вернул новый порт и отказал неверному origin.

Сетевые тесты и итоговая проверка EXE прошли вне песочницы: внутри неё были тайм-ауты локальных соединений и отказ удаления временного EXE.

Полная установка с UAC, запись HKLM, создание системных ярлыков, удаление из Program Files и реальное подключение расширения к установленному Chrome в этой сессии не выполнялись. Рабочая VPN-подписка и внешние VPN-серверы не проверялись. Настройки текущего Chrome не менялись.
