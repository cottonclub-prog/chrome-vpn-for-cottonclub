# Проверка 1.3.0 — настраиваемые домены и IP

Дата: 29 сентября 2026. Среда: Windows 11 x64, Python 3.14.4, PyInstaller 6.19.0, Node.js 25.9.0, sing-box 1.14.1.

## Выполнено

- Встроенные domain/domain_suffix/domain_regex/domain_keyword списки очищены. В IP-списке остались только публичные российские диапазоны (10 870 записей), удалены локальные и непубличные исключения. Исходные четыре правила читаются из `extension/routing-defaults.json`; сборка копирует тот же файл для помощника.
- Пользовательские правила проходят проверку типа, направления, домена/IDN, IPv4/IPv6 и CIDR. Некорректные правила и произвольные действия sing-box отклоняются; максимум 500 строк. Проверены пустой список, отключение правил и игнорирование правил в режиме «Всё через VPN».
- Реальный локальный Hysteria 2-сервер подтвердил изменение маршрута при перестановке правил: `example.ru → VPN` выше `.ru → Напрямую` использует VPN, ниже — прямой маршрут. Пустой список отправляет домен через VPN. Без добавленных пользователем правил локальные имена также идут через VPN; ручные правила для локальных доменов/IP работают напрямую.
- Проверены сохранение нормализованных правил через Native Messaging, восстановление после перезапуска worker, миграция к четырём исходным правилам, сохранение пустого списка и запрет изменения при активном VPN.
- `tests/routing_ui_smoke.py` открыл настоящую страницу редактора в изолированном headless Chrome при ширине 1100 и 560 пикселей. Добавление, редактирование, перестановка, удаление всех правил, сохранение и восстановление исходных прошли. Горизонтального переполнения нет; скриншот просмотрен. RPC расширения в этой проверке подменён; пользовательский профиль Chrome не менялся.

- 47 Python-тестов без пропусков: импорт только Hysteria 2, фильтрация смешанных/Base64-подписок, отказ VLESS и других протоколов, TLS/SNI, Salamander, диапазоны портов, маршрутизация, Native Messaging, диагностика и обновления.
- Новые интеграционные тесты используют настоящий локальный Hysteria 2-сервер и разные HTTP-ответы для прямого и VPN-маршрутов. На прежнем коде все шесть зарубежных доменов проходили в режиме «Всё через VPN» и падали в раздельном режиме, когда тестовый сервер запрещал доступ к Cloudflare DNS. После исправления оба режима проходят. Проверены также прямые российские/локальные имена и IP, сохранение прямого локального доступа при недоступном VPN и отсутствие автоматического прямого обхода для зарубежного домена.
- Имена `chatgpt.com`, `cdn.oaistatic.com`, `files.oaiusercontent.com`, `openai.com`, `challenges.cloudflare.com` в тесте обслуживаются локальными заглушками. Настоящие сайты не запрашиваются. Локальный DNS намеренно возвращает для них прямой адрес: VPN-маршрут сохраняет исходное имя и не использует этот ответ.
- `sing-box check` принял 8 сочетаний: обычный Hysteria 2, доменный адрес, Salamander, mport — в двух режимах маршрутизации.
- Локальный Hysteria 2-сервер передал HTTP-трафик через SOCKS5, включая доменное имя назначения. Проверены запуск sing-box по умолчанию, удаление временной конфигурации и завершение ядра при отключении.
- 14 JavaScript-тестов прошли с `--test-isolation=none` (песочница запрещает дочерний процесс стандартного test runner). API Chrome имитируется. Проверены запрет запуска обновления из Downloads/исходников без отметки установщика, блокировка преждевременной перезагрузки, сохранение ожидания при перезапуске worker, ошибки установки, несовпадающая версия файлов и устаревший результат другой попытки.
- `tests/updater_smoke.ps1` запускает настоящий PowerShell-обновлятор в изолированной папке с подменённым загрузчиком. Проверены передача Quiet/Latest, подтверждение установленной версии и запись ошибки без блокирующих окон. Реальная установка этим тестом не выполняется.
- При диагностике существующей установки подтверждено, что Chrome загружал расширение из Downloads, а пользовательская папка установки содержала отдельную копию 1.2.0. Настройки Chrome не редактировались. Версия 1.2.2 создаёт отметку установленной папки и требует её перед автоматическим обновлением.
- Проверен синтаксис PowerShell и JavaScript, `git diff --check`.
- Регрессионные проверки установочных скриптов подтверждают пользовательские папки и HKCU, отсутствие RunAs, HKLM и общих ярлыков. Обновление разрешено только из пользовательского пути. Новое имя Native Messaging host согласовано в расширении и установщике.
- Готовый ZIP проверен через `tests/package_smoke.py`: CRC, SHA-256 файлов, единственное ядро sing-box, запуск EXE и framing, отказ постороннему origin, принятие Hysteria 2 и отказ VLESS. Манифесты упакованных EXE не требуют повышения прав.
- Установщик в режиме VerifyOnly принимает целый комплект и отклоняет повреждённый. Windows и Chrome при этом не изменяются.
- `tests/bootstrap_smoke.ps1` прошёл: загрузка фиксированной версии и Latest с локальной имитацией скачивания, отказ для неопубликованной сборки, постороннего URL, сетевого сбоя и повреждённого архива.
- Загрузчик выполняет проверенный установочный скрипт в том же PowerShell-процессе, без отдельного запуска PowerShell из временной папки и без повышения прав.

## Границы проверки

Полная установка и удаление в настоящем профиле Windows, запись HKCU, создание ярлыков и подключение расширения в настоящем Chrome не выполнялись. Отсутствие запроса администратора подтверждено кодом установщика/обновления/удаления и манифестами EXE; интерактивная установка не проверялась.

Внешняя подписка пользователя не предоставлена; внешние VPN-серверы и маршрутизация российских адресов не проверены. Существующая системная установка, настройки Chrome, политики Windows и антивируса не изменялись. Совместимость с корпоративными ограничениями и отсутствие антивирусных срабатываний не подтверждены.

Релиз v1.3.0 опубликован. С GitHub скачан ZIP ветки main; его Install.ps1 -VerifyOnly самостоятельно скачал комплект 1.3.0, проверил SHA-256 и целостность файлов. Проверка прошла без установки и изменения Windows/Chrome; временная папка проверки находилась внутри рабочего каталога.
