## Проверка 1.6.5 — автоматический порт

6 октября 2026: общий порт 17892 удалён из помощника и расширения. Production Core запускает sing-box с listen_port=0: Windows выделяет и занимает свободный порт атомарно. Номер читается из объявления TCP-listener inbound/mixed[browser] в выводе только собственного процесса. Вывод потребляется без сохранения исходных строк, доменов и секретов; диагностика хранит только номер порта и фиксированные категории ошибок. Готовность SOCKS5 и HTTPS проверяются на фактическом порту; disconnected-status возвращает null.

Расширение проверяет connected=true и целочисленный порт 1–65535, блокирует старый порт перед перезапуском и применяет только проверенный номер своего помощника. При потере ядра/помощника и восстановлении worker используется SOCKS5 127.0.0.1:0 с отключением loopback-bypass; таким образом освобождённый порт другого пользователя не используется. Проверен разрыв Native Messaging во время применения нового порта. Явное отключение восстанавливает прежние настройки Chrome.

Проверки: 55 Python-тестов, включая два реальных sing-box с автоматически выделенными разными портами при занятом 17892, независимый перезапуск, локальный Hysteria 2, маршрутизацию и Native Messaging; 24 Node.js-теста управления расширением. Popup проверен в отдельном Chrome. tests/proxy_block_smoke.py проверяет реальный Chrome с блокирующим endpoint: локальный HTTP-origin доступен напрямую до и после проверки, а через SOCKS5-порт 0 не получает запросов, включая loopback. Новый помощник собирается из изменённых исходников; в ZIP, EXE и CRX включаются согласованные версии. Пользовательская установка, профиль, сервер подписки и другие пользователи Windows не менялись. Одновременные ядра проверены в одной тестовой сессии; реальные учётные записи Windows для теста не создавались.
