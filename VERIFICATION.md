# Проверка копии Chrome VPN for CottonClub — 28 сентября 2026

## Автоматическая установка из исходников, версия 1.0.2

- Готовый комплект опубликован в GitHub Releases под тегом `v1.0.2`, автор релиза — `cottonclub-prog`. SHA-256 на GitHub совпала с локальным архивом и `release.json`.
- Проверены запуск `Install.ps1 -VerifyOnly` из исходников с локальной подменой скачивания, отказ при недоступной сети и отказ при неверной SHA-256.
- Затем скачан настоящий ZIP исходников тега с GitHub. Его `Install.ps1 -VerifyOnly` самостоятельно скачал публичный релиз, распаковал и успешно проверил готовый комплект без Python и без изменений Windows/Chrome.
- Проверены синтаксис PowerShell и готовый EXE/ZIP через `tests/package_smoke.py`.
- Проверка не подтверждает устранение проблемы VLESS конкретного сервера: версия 1.0.2 меняет доставку установщика, сохраняя диагностику 1.0.1.

## Проверка помощника и расширения

- Собран `dist/Chrome-vpn-for-cottonclub-Windows-x64.zip`, около 48 МиБ. Использованы имеющиеся ядра Xray/sing-box из исходного проекта (`-SkipDownload`), новая загрузка ядер не проверялась.
- Для версии 1.0.1 прошли 25 Python-тестов: импорт подписок, Native Messaging, конфигурация Reality, проверка SOCKS5, занятый порт, завершение процессов, реальные локальные соединения VLESS через Xray и Hysteria 2 через sing-box, а также безопасная классификация ошибок. Помощник пересобран с диагностикой; реальное проблемное VLESS-подключение пользователя не воспроизведено.
- 4 JavaScript-теста: сохранение блокирующего прокси, отключение, восстановление очереди команд, выбранный сервер. Chrome API в этих тестах имитируется.
- Проверен синтаксис PowerShell-установщика, удаления, сборки и запуска, а также обоих JavaScript-файлов.
- Проверены CRC архива и SHA-256 всех файлов; режим `Install.ps1 -VerifyOnly` принимает целый комплект и отклоняет повреждённый без повышения прав.
- Готовый `ZXC-AdminHost.exe` обработал framed JSON-команды status/load/disconnect, вернул новый порт и отказал неверному origin.

Сетевые тесты и итоговая проверка EXE прошли вне песочницы: внутри неё были тайм-ауты локальных соединений и отказ удаления временного EXE.

Полная установка с UAC, запись HKLM, создание системных ярлыков, удаление из Program Files и реальное подключение расширения к установленному Chrome в этой сессии не выполнялись. Рабочая VPN-подписка и внешние VPN-серверы не проверялись. Настройки текущего Chrome не менялись.

Повторная проверка из папки проекта:

```powershell
src/.venv/Scripts/python.exe -B tests/run.py
node --test tests/extension.test.cjs
src/.venv/Scripts/python.exe -B tests/package_smoke.py
```
