# Проверка версии 1.1.0 на sing-box — 29 сентября 2026

Исходная база: cottonclub-prog/chrome-vpn-for-cottonclub, версия 1.0.3. Проверки старых релизов не считаются проверками новой версии.

## Подтверждено

- Официальный sing-box 1.14.1 Windows amd64 скачан через `src/prepare.py`; SHA-256 архива сверена с digest GitHub. Сборка включает QUIC и uTLS.
- 32 Python-теста прошли без пропусков: подписки, конфигурации, Native Messaging, диагностика, проверка соединения, обновления.
- `sing-box check` принял 18 сочетаний: VLESS TCP, доменное имя сервера, WS, gRPC, TLS, Reality/Vision, Hysteria 2, Salamander, список/диапазоны портов — каждый в режимах `all` и `ru-direct`.
- Реальные локальные соединения VLESS и Hysteria 2 передали HTTP-трафик через SOCKS5, включая доменное имя назначения. В обоих тестах проверено использование `sing-box.exe` по умолчанию, удаление временной конфигурации и завершение ядра при отключении.
- Исправлен найденный тестами импорт `mport`: одиночный порт преобразуется в диапазон `443:443`; неверные порты и обратные диапазоны отклоняются.
- 7 JavaScript-тестов прошли: состояние прокси, восстановление после перезапуска, обновление, выбор сервера. API Chrome имитируется.
- Синтаксис PowerShell-скриптов и JavaScript проверен.
- Обновления отклоняют прежний архив с двумя ядрами; имя нового архива содержит `sing-box`.

Среда: Windows 11 x64, Python 3.14.4, PyInstaller 6.19.0, Node.js 25.9.0. Первые запуски внутри песочницы столкнулись с PermissionError/EPERM; итоговые тесты выполнены вне неё.

## Готовый комплект

- Собран `dist/Chrome-vpn-for-cottonclub-sing-box-Windows-x64.zip`, 39 191 074 байт.
- SHA-256: `781c1a41cb034852cc9a5c9bfd60ad1e7b6e270640c2a5dc1f0ae16ff82da758`.
- `tests/package_smoke.py` прошёл: CRC ZIP, SHA-256 файлов, единственное ядро `sing-box.exe`, отсутствие Xray, проверка установщика, отказ после повреждения файла, команды status/load/disconnect готового EXE и отказ неверному origin.
- `tests/bootstrap_smoke.ps1` прошёл: исходный вход установки, режим Latest, отказ для неопубликованной сборки, постороннего URL, сетевого сбоя и неверной SHA-256. Скачивание имитировалось локальным архивом.

- `git diff --check` не обнаружил ошибок.

## Границы проверки

Внешняя VPN-подписка не предоставлена. Подключение к реальному серверу пользователя, включая Reality, не проверено; для Reality проверялась конфигурация, для VLESS и Hysteria 2 — локальная передача трафика. Режим `ru-direct` проверен на принятие конфигурации ядром, без внешней проверки российских адресов.

Установка с UAC, изменения HKLM/Program Files, загрузка расширения в настоящий Chrome и системное удаление не выполнялись. Настройки текущего Chrome не изменялись. Перед публикацией комплект повторно собран с обновлёнными README и встроенной справкой; проверки ZIP/EXE и загрузчика повторно пройдены. Реальная загрузка из GitHub проверяется после публикации релиза.
