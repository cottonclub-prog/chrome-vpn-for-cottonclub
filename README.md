# Chrome VPN for CottonClub — sing-box

Версия 1.1.0 на основе [исходного проекта](https://github.com/cottonclub-prog/chrome-vpn-for-cottonclub). Дизайн расширения и принцип работы сохранены: обычный Google Chrome → Native Messaging → локальный SOCKS5-прокси → VPN. **VLESS и Hysteria 2 работают через одно ядро sing-box 1.14.1.** Xray не скачивается, не упаковывается и не запускается.

## Установка из репозитория — без Python и сборки

Нужны Windows 10/11 x64, установленный Google Chrome, интернет, права администратора для установки помощника и действующая VPN-подписка.

1. На [странице проекта](https://github.com/cottonclub-prog/chrome-vpn-for-cottonclub) нажмите **Code → Download ZIP**.
2. Полностью распакуйте скачанный ZIP в обычную папку. Не запускайте установщик внутри архива.
3. Откройте распакованную папку проекта и запустите **Install.cmd**. Он сам скачает готовый комплект версии 1.1.0 из GitHub Releases, проверит SHA-256 и запустит установку. **Python, Node.js и ручная сборка не нужны.**
4. Подтвердите запрос администратора Windows (UAC).
5. В Chrome откройте `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите `C:\Program Files\Chrome VPN for CottonClub\extension`. Точный путь также покажет установщик. Выбирайте установленную папку, а не `extension` из скачанных исходников.
6. Закрепите значок CottonClub на панели Chrome и настройте подключение по инструкции ниже.

Если Chrome не открылся автоматически, откройте его обычным способом или воспользуйтесь ярлыком Chrome VPN for CottonClub. Chrome не нужно запускать от администратора. Если GitHub недоступен, восстановите подключение и повторите `Install.cmd`.

### Установка готового комплекта

Можно сразу скачать [установочный ZIP 1.1.0](https://github.com/cottonclub-prog/chrome-vpn-for-cottonclub/releases/download/v1.1.0/Chrome-vpn-for-cottonclub-sing-box-Windows-x64.zip) из [Releases](https://github.com/cottonclub-prog/chrome-vpn-for-cottonclub/releases/tag/v1.1.0). Полностью распакуйте его, запустите `Install.cmd` и выполните шаги 4–6 выше. Этот архив уже содержит помощник и ядро; их скачивание при установке не требуется.

Установщик проверяет SHA-256 файлов до установки. Помощник и ядро работают с правами пользователя; системные службы и драйверы не устанавливаются. Ручная загрузка расширения в Chrome сохранена. Корпоративные политики могут её запрещать.

Эта версия заменяет исходную установку. ID расширения `hooimhadihhgfkhidbmjoaojfljafnaf`, Native Messaging host `com.projectzxc.admin` и порт `127.0.0.1:17892` сохранены. Перед заменой отключите VPN и выключите расширение, установите новый комплект, затем включите/перезагрузите расширение. Подписка и настройки сохраняются в Chrome. Одновременная установка двух вариантов не предусмотрена. Старые каталоги помощника могут оставаться до удаления приложения, но новое подключение использует только sing-box.

## Как пользоваться

1. Нажмите значок **CottonClub** в Chrome.
2. В поле **Подписка** вставьте HTTPS-ссылку подписки, ссылку VLESS/Hysteria 2 или Base64-список. Нажмите **Загрузить**.
3. Выберите сервер из списка.
4. Выберите маршрутизацию: **Россия и локальная сеть — напрямую** или **Всё через VPN**.
5. Нажмите **Подключить**. Дождитесь статуса подключения и IP VPN, затем открывайте сайты в этом профиле Chrome.
6. Чтобы завершить работу, нажмите **Отключить VPN**. Для смены сервера, подписки или режима сначала отключитесь.

Подписка, сервер и режим сохраняются локально. Окно расширения можно закрыть: подключение продолжит работать. После перезапуска Chrome откройте расширение и подключитесь снова.

### Поддерживаемые подключения

Поддерживаются HTTPS/Base64-подписки и ссылки `vless://`, `hysteria2://`, `hy2://`:

- VLESS: TCP/raw, WebSocket, gRPC; TLS и Reality, включая `xtls-rprx-vision`.
- Hysteria 2: TLS, Salamander и диапазоны портов `mport`.
- Маршрутизация: «Россия и локальная сеть — напрямую» или «Всё через VPN».

Ссылки с отключённой проверкой сертификатов, XHTTP, JSON/Clash и неподдерживаемыми параметрами не поддерживаются. Наличие протокола в ядре не гарантирует совместимость с любыми настройками сервера.

VPN действует в обычных окнах данного профиля Chrome. Другие приложения и инкогнито не охватываются. После перезапуска браузера подключитесь заново. Перед сменой сервера или маршрутизации отключите VPN. При сбое помощника прокси остаётся включённым до переподключения или явного отключения, чтобы трафик не ушёл напрямую. Кнопка «Отключить VPN» восстанавливает прежние настройки прокси.

Подписка хранится локально в Chrome без дополнительного шифрования. Идентификатор устройства: `%LOCALAPPDATA%\ZXC-Desktop\device-id.txt`. Проверка IP обращается к `api.ipify.org` через VPN. Временный файл с конфигурацией удаляется после запуска; сырые журналы ядра не сохраняются и не передаются расширению.

## Сборка

Нужен Python x64 с pip (проверка текущей сборки описана в `VERIFICATION.md`) и интернет:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Build.ps1
```

Скрипт создаёт `src/.venv`, устанавливает зависимости из `src/requirements.lock`, скачивает официальный sing-box с проверкой SHA-256 GitHub и собирает помощник. `-SkipDownload` использует готовые `src/bin/sing-box.exe`, `LICENSE-sing-box.txt` и `SOURCE.txt`. В архив попадают только эти файлы ядра, даже если в рабочей папке остался Xray.

Результат: установочный ZIP в `dist/` и `dist/release.json` с версией и SHA-256 архива. Готовый комплект не требует Python. EXE и установщик не имеют подписи издателя.

## Обновления

Кнопки обновления сохранены. Загрузчик принимает только архив **Chrome-vpn-for-cottonclub-sing-box-Windows-x64.zip** из стабильного релиза указанного репозитория с опубликованной SHA-256. Старый архив с двумя ядрами отклоняется.

Для обновления через окно расширения нажмите **Проверить обновления**, затем **Обновить — VPN отключится**. Подтвердите UAC, дождитесь завершения или отмены установки и нажмите **Перезагрузить расширение**. Пока установщик работает, не перезагружайте расширение и не открывайте его в другом профиле Chrome.

Для перехода со старой версии можно заново скачать проект: отключите VPN, выключите расширение на `chrome://extensions`, запустите новый `Install.cmd`, затем включите/перезагрузите расширение. Удалять расширение для обновления не нужно: так сохраняются подписка и настройки.

В Git хранятся только исходники, скрипты, правила маршрутизации, тесты и документация. Готовые EXE и ZIP публикуются в Releases. Версия и SHA-256 установочного архива зафиксированы в корневом `release.json`; временные файлы загрузчика удаляются после завершения.

Для сопровождающего: после сборки публикуйте ZIP из `dist/` под тегом `v<версия>` и переносите `dist/release.json` в корень репозитория. Проверка загрузки без установки: `powershell -NoProfile -ExecutionPolicy Bypass -File Install.ps1 -VerifyOnly`.

## Ошибки и удаление

«Помощник недоступен» — повторите установку полного комплекта и перезагрузите расширение. «Лимит устройств» — проверьте подписку в панели поставщика. Занятый порт — закройте другую копию помощника. Ошибки Reality/TLS — проверьте SNI, ключ, shortId, сертификат сервера и дату Windows. Настройки прокси могут управляться другим расширением или политикой организации.

Для удаления отключите VPN, удалите расширение в Chrome и удалите Chrome VPN for CottonClub через список приложений Windows. Общий идентификатор устройства и пользовательские данные сохраняются.

## Структура

- `extension/` — исходный интерфейс и управление Chrome.
- `src/runtime.py` — единый запуск, проверка и остановка sing-box.
- `src/subscription.py` — подписки и конфигурации обоих протоколов.
- `src/routing_policy.py`, `src/routing/` — маршрутизация и источники правил.
- `src/prepare.py`, `Build.ps1` — загрузка ядра и сборка комплекта.
- `Install.*`, `Launch.*`, `Uninstall.*` — установка и удаление.
- `Bootstrap.ps1`, `Update.ps1`, `src/updates.py` — проверка и доставка обновлений.
- `tests/` — автоматические проверки.
