# CottonClub VPN for Chrome — только Hysteria 2

Версия **1.6.6**: расширение Google Chrome с ядром **sing-box 1.14.1**, только для **Hysteria 2**. Установка, обновление и удаление выполняются **для текущего пользователя Windows без запроса прав администратора**. Домены, IP и маршруты настраиваются прямо в расширении. Локальный порт выбирается автоматически, поэтому разные пользователи Windows могут подключаться одновременно.

## Установка из репозитория

Нужны Windows 10/11 x64, Google Chrome, интернет и подписка с серверами Hysteria 2. Python и сборка не нужны.

### EXE с прогрессом установки

Скачайте [cottonclub-vpn-for-chrome-setup-1.6.6.exe](https://github.com/cottonclub-prog/cottonclub-vpn-for-chrome/releases/download/v1.6.6/cottonclub-vpn-for-chrome-setup-1.6.6.exe) и запустите обычным двойным щелчком. EXE содержит весь комплект, интернет для установки не нужен. Нажмите **Установить**: окно покажет проверку архива, распаковку, проверку контрольных сумм и установку. При обновлении сначала отключите VPN и выключите расширение в `chrome://extensions`.

После завершения нажмите **Закрыть**. Если отмечено «Открыть расширения Chrome и папку установки», установщик откроет `chrome://extensions/` в новом окне Chrome и установленную папку в Проводнике. При первой установке и переходе со старой папки выберите новую папку расширения. Последующие обновления требуют только перезагрузки расширения. EXE не меняет профили Chrome и не устанавливает корпоративные политики автоматически. Подписка и правила прежнего распакованного расширения сохраняются. EXE пока не имеет подписи издателя Authenticode.

### CRX для корпоративной установки

Готовые файлы: [cottonclub-vpn-for-chrome.crx](https://github.com/cottonclub-prog/cottonclub-vpn-for-chrome/releases/download/v1.6.6/cottonclub-vpn-for-chrome.crx) и [updates.xml](https://github.com/cottonclub-prog/cottonclub-vpn-for-chrome/releases/latest/download/updates.xml).

CRX подписан отдельным ключом и имеет ID **pppgaipmgmbndhejmkabemifkonbgooh**. Прежнее распакованное расширение сохраняет ID **hooimhadihhgfkhidbmjoaojfljafnaf**. Помощник принимает оба ID. При переходе на CRX сохраните ссылку подписки, выключите прежнюю запись и настройте подписку и правила в новой: Chrome хранит данные разных ID отдельно. Не включайте обе записи одновременно.

Для автоматической установки администратор управляемого Chrome задаёт в политике **ExtensionInstallForcelist** значение:

```text
pppgaipmgmbndhejmkabemifkonbgooh;https://github.com/cottonclub-prog/cottonclub-vpn-for-chrome/releases/latest/download/updates.xml
```

В Windows установка CRX вне Chrome Web Store через политики требует поддерживаемого корпоративного управления (AD/Entra ID или Chrome Enterprise Core). Перетаскивание CRX в обычный Chrome не является гарантированным способом установки. Установщик EXE нужен на каждом компьютере для помощника и sing-box; сама корпоративная политика ставит только CRX. Обновления CRX выполняет Chrome по XML, а помощник/ядро обновляются новым EXE или ZIP. В корпоративном CRX кнопка установки обновления из popup скрыта, чтобы не обновлять другую распакованную копию.

1. На [странице проекта](https://github.com/cottonclub-prog/cottonclub-vpn-for-chrome) нажмите **Code → Download ZIP**.
2. Полностью распакуйте ZIP в обычную папку.
3. Запустите **Install.cmd** обычным двойным щелчком. **«Запуск от имени администратора» не нужен.** Загрузчик скачает готовый комплект 1.6.6 и проверит SHA-256.
4. Откройте `chrome://extensions`, включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**.
5. Выберите установленную папку `%LOCALAPPDATA%\CottonClub VPN for Chrome\CottonClub VPN for Chrome`. Вставьте этот путь в адресную строку окна выбора папки; установщик также покажет полный путь. Не выбирайте `extension` из исходников.
6. Закрепите значок CottonClub на панели Chrome.

Альтернатива: скачайте [готовый установочный ZIP 1.6.6](https://github.com/cottonclub-prog/cottonclub-vpn-for-chrome/releases/download/v1.6.6/cottonclub-vpn-for-chrome-windows-x64.zip), распакуйте и запустите `Install.cmd`. Этот архив уже содержит помощник и ядро; при установке не потребуется их скачивание.

Файлы и данные помощника хранятся в одной папке `%LOCALAPPDATA%\CottonClub VPN for Chrome`: внутри `CottonClub VPN for Chrome` — само расширение, `host` — помощник и sing-box, `device-id.txt` — идентификатор, `update.log` — результат последнего обновления. Новые папки с копиями каждого выпуска не создаются. В popup заголовок **COTTONCLUB VPN**, под ним **FOR CHROME**. Регистрация помощника и удаления — в `HKEY_CURRENT_USER`, ярлыки создаются только для текущего пользователя. Program Files, HKLM, службы, драйверы и общие ярлыки не изменяются. Повышения прав через UAC нет.

Если установлена прежняя версия 1.1.0 или старше: отключите VPN, сохраните ссылку подписки и выключите старое расширение. Загрузите расширение из нового пользовательского пути. Если Chrome не позволяет заменить старую запись с тем же ID, удалите старую запись расширения, загрузите новую и заново вставьте сохранённую подписку. Старый системный помощник не удаляется и не используется новой версией; удаление старой установки из Program Files отдельно может потребовать администратора. Новая версия этого не запрашивает.

## Как пользоваться

1. Нажмите значок **CottonClub**.
2. Откройте вкладку **Настройки** и вставьте HTTPS-ссылку подписки, ссылку `hysteria2://` / `hy2://` или Base64-список в поле **Ссылка подписки**. Кнопка с глазом показывает или скрывает ссылку.
3. Нажмите **Обновить серверы**. Из смешанной подписки будут выбраны только серверы Hysteria 2; остальные строки пропускаются. Если Hysteria 2 нет, появится ошибка.
4. На вкладке **VPN** нажмите карточку сервера и выберите подключение. Выберите **По правилам** либо **Всё через VPN**.
5. Нажмите круглую кнопку питания и дождитесь статуса **Подключено** и IP VPN. Оранжевый цвет кнопки и статуса означает активное подключение.
6. Для отключения нажмите кнопку питания повторно. Перед сменой сервера, подписки или режима отключитесь.

Вкладка **Правила** открывается в том же окне. Нажмите **Добавить**, выберите тип адреса, введите домен/IP/подсеть и укажите **Напрямую** или **Через VPN**. В редакторе можно выключить правило, изменить приоритет или удалить его. Нажмите **Готово**, затем **Сохранить правила** до закрытия окна: несохранённые правки не сохраняются при закрытии popup. Сохранённые правила применяются при следующем подключении. Обновление приложения находится на вкладке **Настройки**.

Подписка, сервер и режим сохраняются локально. Окно расширения можно закрыть. После перезапуска Chrome подключитесь снова. VPN действует только в обычных окнах данного профиля Chrome; другие приложения и инкогнито не охватываются.

Поддерживаются TLS/SNI, Salamander и списки/диапазоны портов `mport`. VLESS, Reality, Hysteria 1, JSON/Clash-конфигурации, `pinSHA256` и ссылки с отключённой проверкой сертификата не поддерживаются. Сеть должна разрешать UDP к серверу Hysteria 2.

При сбое помощника прокси остаётся включённым до переподключения или явного отключения VPN. «Отключить VPN» восстанавливает прежние настройки Chrome.

### Как выбирается маршрут

В режиме **По правилам** исходный список содержит ровно четыре включённых правила: **IP России → Напрямую**, **.ru → Напрямую**, **.su → Напрямую**, **.рф → Напрямую**. Отдельный список российских доменов и скрытые исключения для локальной сети удалены. Ранее выбранный раздельный режим после обновления использует эти четыре правила.

Откройте вкладку **Правила** в popup. Для каждой строки можно выбрать тип **Домен и поддомены**, **IP / подсеть** или **IP России**, ввести адрес, выбрать **Через VPN** / **Напрямую**, отключить правило флажком, удалить его или переместить стрелками. Перед сохранением отключите VPN. Нажмите **Сохранить правила** и подключитесь заново. Правила сохраняются в данном профиле Chrome и переживают обновление расширения. **Вернуть исходные** восстанавливает четыре исходные строки только после подтверждения и сохранения.

Порядок важен: срабатывает **первое совпадение сверху**. Например, чтобы `example.ru` шёл через VPN, поставьте его правило выше общего `.ru → Напрямую`. Домены включают поддомены; вводите их без `https://`, пути и порта. `.рф` автоматически преобразуется в `xn--p1ai`.

IP поддерживаются как отдельные IPv4/IPv6-адреса, так и подсети CIDR: `192.168.1.10`, `192.168.0.0/16`, `fc00::/7`. **IP-правила, включая IP России, применяются к обращениям непосредственно по IP.** Предварительного DNS-разрешения домена для проверки его страны или подсети нет. Для локального ресурса по имени добавьте отдельное правило, например `printer.local → Напрямую`; имя должно разрешаться DNS вашей сети. Локальные IP не входят в группу IP России.

Всё, что не совпало с правилами, идёт через VPN. Пустой список тоже означает всё через VPN. В режиме **Всё через VPN** весь пользовательский список временно игнорируется. Зарубежные домены передаются Hysteria 2-серверу без обязательного запроса к Cloudflare DNS. При недоступном VPN автоматического перехода на прямое соединение нет.

Исходные редактируемые правила находятся в `CottonClub VPN for Chrome/routing-defaults.json`; российские IP — в `src/routing/ru-direct.json` с источником и контрольной суммой в `SOURCES.json`. Для обычного изменения правил файлы править не нужно.

## Обновление и удаление

**Первый переход на 1.6.6:** отключите VPN и выключите расширение в `chrome://extensions`. Запустите новый EXE или `Install.cmd` вручную. Установщик переименует прежнюю папку установки и внутреннюю папку расширения, сохранит идентификатор устройства и заменит помощник. Затем нажмите «Загрузить распакованное расширение» и выберите `%LOCALAPPDATA%\CottonClub VPN for Chrome\CottonClub VPN for Chrome`, не удаляя существующую запись расширения. ID сохранён, поэтому подписка и правила остаются в том же хранилище Chrome. Простая перезагрузка старой папки после её переноса не подходит. Из-за переименования репозитория автоматическая проверка обновлений в прежних версиях может завершиться ошибкой: этот переход выполните вручную. После перехода обновление из popup снова работает.

В расширении нажмите **Проверить обновления**, затем **Обновить — VPN отключится**. Дождитесь сообщения **«Версия … установлена»**: только после проверки файлов станет доступна кнопка **Перезагрузить расширение**. При автоматическом обновлении отдельные окна подтверждения установщика не нужны. Обновление не запрашивает администратора. Во время установки не открывайте расширение в других профилях Chrome.

**Если после обновления в 1.2.0/1.2.1 осталась старая версия:** отключите VPN, выключите CottonClub в `chrome://extensions`, скачайте готовый ZIP 1.6.6 по ссылке выше, распакуйте и запустите `Install.cmd`. После сообщения об установке включите расширение и нажмите кнопку перезагрузки на его карточке в `chrome://extensions`. Если версия по-прежнему старая, Chrome использует другую папку: сохраните ссылку подписки и загрузите `%LOCALAPPDATA%\CottonClub VPN for Chrome\CottonClub VPN for Chrome`. Удаление старой записи расширения может потребовать повторного ввода подписки.

Начиная с 1.2.2, расширение проверяет, загружено ли оно из установленной папки. Копия из Downloads или исходников не обновляется автоматически: появится инструкция по выбору правильной папки. Ошибка установки отображается в расширении, а вывод обновлятора сохраняется в `%LOCALAPPDATA%\CottonClub VPN for Chrome\update.log`. При ошибке кнопка **Вернуться к расширению** позволяет продолжить работу со старой версией. Если процесс не подтвердил завершение, установите комплект вручную после выключения расширения; обычная перезагрузка сама по себе новую версию не устанавливает.

Для ручного обновления отключите VPN, выключите расширение, запустите `Install.cmd` из нового комплекта и включите/перезагрузите расширение. После перехода на 1.6.6 путь постоянный, подписка сохраняется.

Удаление: отключите VPN и удалите расширение в Chrome, затем запустите `%LOCALAPPDATA%\CottonClub VPN for Chrome\Uninstall.cmd` или удалите **CottonClub VPN for Chrome** через список приложений Windows. Удаляются только файлы и регистрация этой пользовательской установки, без прав администратора. `device-id.txt` сохраняется в общей папке приложения для последующей переустановки. Подписка и правила находятся в хранилище Chrome и удаляются самим Chrome при удалении расширения.

## Если установка или подключение не работает

- **Chrome 138: `chrome.storage.local.setAccessLevel is not a function`:** исправлено начиная с 1.4.2. Если окно расширения не работает, выключите расширение в `chrome://extensions` и установите новый комплект вручную. При переходе на 1.6.6 выберите новую папку, как описано выше. ID расширения и сохранённые настройки сохраняются. Проверка наличия метода выполняется перед вызовом; `session.setAccessLevel` остаётся включённым.
- **Первое обновление изменило папку установки:** выберите новую папку `%LOCALAPPDATA%\CottonClub VPN for Chrome\CottonClub VPN for Chrome` через «Загрузить распакованное расширение», не удаляя прежнюю запись. Далее обновления используют этот постоянный путь.
- **Помощник недоступен:** повторите установку и проверьте, что расширение загружено из пользовательского пути, указанного выше.
- **Нет поддерживаемых подключений:** в подписке должны быть серверы Hysteria 2. Ссылки VLESS эта версия не использует.
- **Тайм-аут подключения:** проверьте доступность сервера и UDP, SNI и пароль. Ошибка сертификата также может быть связана с неверной датой Windows.
- **Всё через VPN работает, а раздельный режим не открывает ChatGPT или другие зарубежные сайты:** обновитесь до 1.2.2, перезагрузите расширение и переподключитесь. В этой версии удалён дополнительный DNS-запрос, который мог блокировать такие соединения. Если проблема сохраняется и в режиме «Всё через VPN», проверьте другой сервер подписки.
- **Лимит устройств:** проверьте подписку в панели поставщика.
- **Управляется другим расширением или администратором:** проверьте другие прокси-расширения и правила организации.
- **Сообщение антивируса:** отсутствие UAC не гарантирует отсутствие антивирусных срабатываний. Эта версия не изменяет настройки антивируса. Подробности блокировки нужно проверять в его отчёте; корпоративные ограничения могут запрещать установку даже без администратора.

## Данные и принцип работы

Иконки расширения, установщика, ярлыка и записи в списке приложений Windows используют синий логотип CottonClub. Исходный SVG сохранён в `CottonClub VPN for Chrome/icons/logo.svg`; PNG и ICO имеют прозрачный фон и сохраняют пропорции логотипа.

Chrome → Native Messaging → локальный SOCKS5 → Hysteria 2 через sing-box. Помощник `cottonclub-vpn-for-chrome-host.exe`, host `com.cottonclub.hysteria2`. Sing-box слушает только `127.0.0.1`: при каждом запуске Windows назначает ему свободный порт, а помощник передаёт фактический номер расширению после проверки соединения. Пользователи Windows и разные профили Chrome используют отдельные экземпляры ядра и могут работать одновременно. Настраивать порт вручную не нужно.

Пока идёт подключение, при потере помощника и после перезапуска расширения с включённым VPN Chrome использует блокирующий SOCKS5-адрес `127.0.0.1:0`. Подключиться к TCP-сервису на порту 0 нельзя; старый порт не сохраняется для трафика, поскольку его мог занять другой пользователь. После переподключения применяется новый проверенный порт. Явное отключение VPN восстанавливает прежние настройки Chrome.

Для перехода на автоматический выбор порта обновите **весь комплект: помощник и расширение** через новый EXE, `Install.cmd` или штатное обновление распакованного расширения. Одно обновление корпоративного CRX не заменяет помощник: для него также запустите новый EXE. ID расширения сохранён: `hooimhadihhgfkhidbmjoaojfljafnaf`.

Подписка хранится локально в Chrome без дополнительного шифрования приложения. Постоянный идентификатор устройства хранится в `%LOCALAPPDATA%\CottonClub VPN for Chrome\device-id.txt`. Установщик переносит прежний идентификатор без изменения, затем удаляет старый файл и пустую папку. Старое название клиента больше не передаётся серверу подписки. Если прежняя папка содержит посторонние файлы или другой идентификатор, они сохраняются. Временная конфигурация ядра создаётся в той же общей папке и удаляется после запуска; сырые журналы не сохраняются и не передаются расширению. Проверка внешнего IP использует `api.ipify.org` через VPN.

## Сборка и проверка

Для сборки CRX и EXE после `Build.ps1` выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Build-Distribution.ps1 -KeyPath .keys/cottonclub-crx.pem
src/.venv/Scripts/python.exe -B tests/setup_smoke.py
```

Нужны Chrome, Node.js и компилятор C# из .NET Framework Windows. `Build-Distribution.ps1` использует свежий ZIP, упаковывает CRX3 через Chrome в отдельном временном профиле, проверяет подпись и ID, создаёт `updates.xml`, компилирует EXE с встроенным ZIP и записывает `SHA256SUMS.txt`. Сторонний конструктор установщиков не требуется. Исходники окна — `installer/Setup.cs`.

Если изменён исходный логотип, перед сборкой выполните `src/.venv/Scripts/python.exe -B installer/render-icons.py`: PNG размеров 16, 32, 48 и 128 и общий `icons/app.ico` будут обновлены через отдельный скрытый профиль Chrome без дополнительных библиотек.

Приватный ключ CRX находится локально в `.keys/cottonclub-crx.pem` и не включается в Git или Releases. Сделайте защищённую резервную копию: для будущих обновлений CRX нужен тот же ключ. В репозитории хранится только публичная идентичность `installer/crx-identity.json`. Если ключ утрачен, обновить CRX с прежним ID нельзя. EXE можно проверить без установки командой `cottonclub-vpn-for-chrome-setup-1.6.6.exe --verify-only`.

Для разработчика нужны Python x64 с pip и интернет; Node.js нужен только для JavaScript-тестов:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Build.ps1
src/.venv/Scripts/python.exe -B tests/run.py
node --test tests/extension.test.cjs
src/.venv/Scripts/python.exe -B tests/package_smoke.py
powershell -NoProfile -ExecutionPolicy Bypass -File tests/bootstrap_smoke.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tests/updater_smoke.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tests/install_files_smoke.ps1
src/.venv/Scripts/python.exe -B tests/routing_ui_smoke.py
```

`Build.ps1 -SkipDownload` использует ранее скачанный sing-box. Результат — `dist/cottonclub-vpn-for-chrome-windows-x64.zip` и `dist/release.json` с SHA-256. В Git находятся только исходники, скрипты, правила маршрутизации, документация и тесты. Готовый комплект публикуется в [Releases](https://github.com/cottonclub-prog/cottonclub-vpn-for-chrome/releases); EXE и ZIP в Git не добавляются.

При публикации ZIP загружается под тегом `v<версия>`, а `dist/release.json` переносится в корень. Загрузчик принимает только архив пользовательской Hysteria 2-версии. Старые архивы с установкой для всей системы не используются. Проверка скачивания без установки: `powershell -NoProfile -ExecutionPolicy Bypass -File Install.ps1 -VerifyOnly`.
