# Chrome VPN for CottonClub — только Hysteria 2

Версия **1.2.2**: расширение Google Chrome с ядром **sing-box 1.14.1**, только для **Hysteria 2**. Установка, обновление и удаление выполняются **для текущего пользователя Windows без запроса прав администратора**. Исправлена зависимость раздельной маршрутизации от дополнительного DNS, из-за которой могли не открываться зарубежные сайты.

## Установка из репозитория

Нужны Windows 10/11 x64, Google Chrome, интернет и подписка с серверами Hysteria 2. Python и сборка не нужны.

1. На [странице проекта](https://github.com/cottonclub-prog/chrome-vpn-for-cottonclub) нажмите **Code → Download ZIP**.
2. Полностью распакуйте ZIP в обычную папку.
3. Запустите **Install.cmd** обычным двойным щелчком. **«Запуск от имени администратора» не нужен.** Загрузчик скачает готовый комплект 1.2.2 и проверит SHA-256.
4. Откройте `chrome://extensions`, включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**.
5. Выберите установленную папку `%LOCALAPPDATA%\Chrome VPN for CottonClub\extension`. Вставьте этот путь в адресную строку окна выбора папки; установщик также покажет полный путь. Не выбирайте `extension` из исходников.
6. Закрепите значок CottonClub на панели Chrome.

Альтернатива: скачайте [готовый установочный ZIP 1.2.2](https://github.com/cottonclub-prog/chrome-vpn-for-cottonclub/releases/download/v1.2.2/Chrome-vpn-for-cottonclub-hysteria2-user-Windows-x64.zip), распакуйте и запустите `Install.cmd`. Этот архив уже содержит помощник и ядро; при установке не потребуется их скачивание.

Файлы устанавливаются в `%LOCALAPPDATA%\Chrome VPN for CottonClub`, регистрация помощника и удаления — в `HKEY_CURRENT_USER`, ярлыки создаются только для текущего пользователя. Program Files, HKLM, службы, драйверы и общие ярлыки не изменяются. Повышения прав через UAC нет.

Если установлена прежняя версия 1.1.0 или старше: отключите VPN, сохраните ссылку подписки и выключите старое расширение. Загрузите расширение из нового пользовательского пути. Если Chrome не позволяет заменить старую запись с тем же ID, удалите старую запись расширения, загрузите новую и заново вставьте сохранённую подписку. Старый системный помощник не удаляется и не используется новой версией; удаление старой установки из Program Files отдельно может потребовать администратора. Новая версия этого не запрашивает.

## Как пользоваться

1. Нажмите значок **CottonClub**.
2. Вставьте HTTPS-ссылку подписки, ссылку `hysteria2://` / `hy2://` или Base64-список в поле **Подписка**.
3. Нажмите **Загрузить**. Из смешанной подписки будут выбраны только серверы Hysteria 2; остальные строки пропускаются. Если Hysteria 2 нет, появится понятная ошибка.
4. Выберите сервер и маршрутизацию: **Россия и локальная сеть — напрямую** либо **Всё через VPN**.
5. Нажмите **Подключить** и дождитесь статуса подключения и IP VPN.
6. Для завершения нажмите **Отключить VPN**. Перед сменой сервера, подписки или режима отключитесь.

Подписка, сервер и режим сохраняются локально. Окно расширения можно закрыть. После перезапуска Chrome подключитесь снова. VPN действует только в обычных окнах данного профиля Chrome; другие приложения и инкогнито не охватываются.

Поддерживаются TLS/SNI, Salamander и списки/диапазоны портов `mport`. VLESS, Reality, Hysteria 1, JSON/Clash-конфигурации, `pinSHA256` и ссылки с отключённой проверкой сертификата не поддерживаются. Сеть должна разрешать UDP к серверу Hysteria 2.

При сбое помощника прокси остаётся включённым до переподключения или явного отключения VPN. «Отключить VPN» восстанавливает прежние настройки Chrome.

### Как выбирается маршрут

В режиме **Россия и локальная сеть — напрямую** прямой маршрут получают домены из встроенного российского списка, зоны `.ru`, `.su`, `.рф`, локальные имена без точки, `.local`, `.lan`, `.localhost`, `.home.arpa`, а также обращения непосредственно к российским и локальным IP-адресам из списка. Эти домены разрешаются средствами Windows, поэтому корпоративные имена требуют доступного DNS вашей сети.

Остальные домены, включая `chatgpt.com`, передаются через Hysteria 2 без предварительного разрешения DNS на клиенте — так же, как в режиме **Всё через VPN**. Обязательного запроса к Cloudflare DNS больше нет. Неизвестный домен останется через VPN, даже если его IP расположен в России: геолокация после DNS для таких доменов не выполняется. При недоступном VPN автоматического перехода этих сайтов на прямое соединение нет.

Списки встроены в комплект и не определяют местоположение каждого сайта в реальном времени. Если нужный российский домен отсутствует в списке, он пойдёт через VPN.

## Обновление и удаление

В расширении нажмите **Проверить обновления**, затем **Обновить — VPN отключится**. Дождитесь сообщения **«Версия … установлена»**: только после проверки файлов станет доступна кнопка **Перезагрузить расширение**. При автоматическом обновлении отдельные окна подтверждения установщика не нужны. Обновление не запрашивает администратора. Во время установки не открывайте расширение в других профилях Chrome.

**Если после обновления в 1.2.0/1.2.1 осталась старая версия:** отключите VPN, выключите CottonClub в `chrome://extensions`, скачайте готовый ZIP 1.2.2 по ссылке выше, распакуйте и запустите `Install.cmd`. После сообщения об установке включите расширение и нажмите кнопку перезагрузки на его карточке в `chrome://extensions`. Если версия по-прежнему старая, Chrome использует другую папку: сохраните ссылку подписки и загрузите `%LOCALAPPDATA%\Chrome VPN for CottonClub\extension`. Удаление старой записи расширения может потребовать повторного ввода подписки.

Начиная с 1.2.2, расширение проверяет, загружено ли оно из установленной папки. Копия из Downloads или исходников не обновляется автоматически: появится инструкция по выбору правильной папки. Ошибка установки отображается в расширении, а вывод обновлятора сохраняется в `%LOCALAPPDATA%\Chrome VPN for CottonClub\update.log`. При ошибке кнопка **Вернуться к расширению** позволяет продолжить работу со старой версией. Если процесс не подтвердил завершение, установите комплект вручную после выключения расширения; обычная перезагрузка сама по себе новую версию не устанавливает.

Для ручного обновления отключите VPN, выключите расширение, запустите `Install.cmd` из нового комплекта и включите/перезагрузите расширение. При обновлении уже установленной пользовательской версии путь постоянный, подписка сохраняется.

Удаление: отключите VPN и удалите расширение в Chrome, затем запустите `%LOCALAPPDATA%\Chrome VPN for CottonClub\Uninstall.cmd` или удалите **Chrome VPN for CottonClub (Hysteria 2, current user)** через список приложений Windows. Удаляются только файлы и регистрация этой пользовательской установки, без прав администратора. Данные подписки и общий идентификатор устройства автоматически не удаляются.

## Если установка или подключение не работает

- **Помощник недоступен:** повторите установку и проверьте, что расширение загружено из пользовательского пути, указанного выше.
- **Нет поддерживаемых подключений:** в подписке должны быть серверы Hysteria 2. Ссылки VLESS эта версия не использует.
- **Тайм-аут подключения:** проверьте доступность сервера и UDP, SNI и пароль. Ошибка сертификата также может быть связана с неверной датой Windows.
- **Всё через VPN работает, а раздельный режим не открывает ChatGPT или другие зарубежные сайты:** обновитесь до 1.2.2, перезагрузите расширение и переподключитесь. В этой версии удалён дополнительный DNS-запрос, который мог блокировать такие соединения. Если проблема сохраняется и в режиме «Всё через VPN», проверьте другой сервер подписки.
- **Лимит устройств:** проверьте подписку в панели поставщика.
- **Управляется другим расширением или администратором:** проверьте другие прокси-расширения и правила организации.
- **Сообщение антивируса:** отсутствие UAC не гарантирует отсутствие антивирусных срабатываний. Эта версия не изменяет настройки антивируса. Подробности блокировки нужно проверять в его отчёте; корпоративные ограничения могут запрещать установку даже без администратора.

## Данные и принцип работы

Chrome → Native Messaging → локальный SOCKS5 → Hysteria 2 через sing-box. Помощник `CottonClub-Host.exe`, host `com.cottonclub.hysteria2`, порт `127.0.0.1:17892`. ID расширения сохранён: `hooimhadihhgfkhidbmjoaojfljafnaf`. Отдельное имя host исключает запуск старого системного помощника.

Подписка хранится локально в Chrome без дополнительного шифрования приложения. Общий HWID `%LOCALAPPDATA%\ZXC-Desktop\device-id.txt` сохранён для совместимости подписок. Временная конфигурация удаляется после запуска ядра; сырые журналы не сохраняются и не передаются расширению. Проверка внешнего IP использует `api.ipify.org` через VPN.

## Сборка и проверка

Для разработчика нужны Python x64 с pip и интернет; Node.js нужен только для JavaScript-тестов:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Build.ps1
src/.venv/Scripts/python.exe -B tests/run.py
node --test tests/extension.test.cjs
src/.venv/Scripts/python.exe -B tests/package_smoke.py
powershell -NoProfile -ExecutionPolicy Bypass -File tests/bootstrap_smoke.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tests/updater_smoke.ps1
```

`Build.ps1 -SkipDownload` использует ранее скачанный sing-box. Результат — `dist/Chrome-vpn-for-cottonclub-hysteria2-user-Windows-x64.zip` и `dist/release.json` с SHA-256. В Git находятся только исходники, скрипты, правила маршрутизации, документация и тесты. Готовый комплект публикуется в [Releases](https://github.com/cottonclub-prog/chrome-vpn-for-cottonclub/releases); EXE и ZIP в Git не добавляются.

При публикации ZIP загружается под тегом `v<версия>`, а `dist/release.json` переносится в корень. Загрузчик принимает только архив пользовательской Hysteria 2-версии. Старые архивы с установкой для всей системы не используются. Проверка скачивания без установки: `powershell -NoProfile -ExecutionPolicy Bypass -File Install.ps1 -VerifyOnly`.

Фактические проверки и их ограничения: [VERIFICATION.md](VERIFICATION.md).
