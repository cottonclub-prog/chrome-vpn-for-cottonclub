# Chrome VPN for CottonClub для обычного Google Chrome

VPN-расширение для CottonClub в Google Chrome с автоматической установкой фонового помощника, Xray и sing-box на Windows 10/11 x64. Отдельное VPN-приложение запускать не нужно. Поддерживаются VLESS и Hysteria 2, HTTPS/Base64-подписки, режимы «Россия напрямую» и «Всё через VPN».

## Что находится в репозитории

Здесь размещены исходники, установщик, правила маршрутизации и тесты. Готовые EXE/ZIP, виртуальные окружения и личные подписки в Git не включены. Архив **Code → Download ZIP** содержит исходники, а не готовый установочный комплект.

Чтобы получить установочный комплект, скачайте и распакуйте исходники, установите Python 3.11 x64 с pip и выполните в папке проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Build.ps1
```

Для сборки нужен интернет. После завершения получите `dist/Chrome-vpn-for-cottonclub-Windows-x64.zip`. Этот архив можно передать пользователям: на их компьютерах Python не нужен. Для использования нужны Windows 10/11 x64, установленный Google Chrome, права администратора для установки помощника и действующая подписка или ссылка VLESS/Hysteria 2.

## Установка готового комплекта

1. Распакуйте **весь** `dist/Chrome-vpn-for-cottonclub-Windows-x64.zip`.
2. Запустите `Install.cmd` внутри распакованной папки и подтвердите UAC. Установщик сам установит ядра, помощник, регистрацию Native Messaging и ярлык настройки. Python и другие зависимости устанавливать не нужно; всё включено в комплект, интернет для установки помощника не требуется.
3. В открывшемся обычном Chrome на странице `chrome://extensions` включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите `C:\Program Files\Chrome VPN for CottonClub\extension` (точный путь показывает установщик).
4. Закрепите расширение, вставьте подписку, загрузите серверы и подключитесь. Ярлык на рабочем столе повторно открывает страницу настройки и папку расширения.

Если установщик запускали уже из повышенной консоли, откройте ярлык из обычного сеанса Windows после установки. Chrome не запускается от администратора. Сам Chrome должен быть установлен заранее.

Один ручной шаг в Chrome обязателен: обычный Chrome на неуправляемом Windows-компьютере не позволяет принудительно установить локальное расширение вне Chrome Web Store только благодаря правам администратора. Политики организации могут запрещать и ручную установку. Установщик не меняет корпоративные политики.

Права администратора нужны для установки в Program Files и регистрации помощника в HKLM. Само расширение не получает права администратора Windows; помощник запускается браузером с правами пользователя. Системные службы и драйверы не устанавливаются, другие приложения через VPN не направляются.

## Как пользоваться

1. Нажмите значок расширения **CottonClub** на панели Chrome.
2. В поле «Подписка» вставьте HTTPS-ссылку подписки, ссылку VLESS/Hysteria 2 или Base64-список и нажмите «Загрузить».
3. Выберите сервер. Перед подключением выберите маршрутизацию: «Россия и локальная сеть — напрямую» или «Всё через VPN».
4. Нажмите «Подключить». Дождитесь статуса «Подключён» и отображения IP VPN, затем открывайте сайты в этом профиле Chrome.
5. Для завершения нажмите «Отключить VPN». Прежние настройки прокси Chrome восстановятся.

Подписка, сервер и режим сохраняются локально. После перезапуска Chrome откройте расширение и снова нажмите «Подключить». Для смены сервера, подписки или маршрутизации сначала отключите VPN. Постоянно держать окно расширения открытым не нужно.

## Если возникла ошибка

Начиная с версии 1.0.1 ошибка проверки соединения содержит протокол, режим маршрутизации и тип сбоя HTTPS/SOCKS5. Если ядро выдало распознаваемую ошибку Reality, сертификата, DNS или сети, добавляется пояснение. Сырые журналы ядра не сохраняются и не выводятся: используются только заранее заданные сообщения без адресов серверов и ключей. Это диагностическое обновление; само по себе оно не гарантирует исправление недоступного VLESS-сервера.

| Сообщение или ситуация | Что сделать |
| --- | --- |
| «Помощник недоступен» | Повторите установку из полного готового комплекта через `Install.cmd`, затем перезагрузите расширение. |
| «Лимит устройств» | Проверьте подписку и список устройств в панели её поставщика. |
| Настройки управляются другим расширением | Отключите другое VPN/прокси-расширение в этом профиле. Если действует политика организации, обратитесь к администратору. |
| После разрыва соединения сайты не открываются | Нажмите «Подключить» повторно или «Отключить VPN». После сбоя помощника прокси намеренно остаётся включённым. |
| Установщик сообщает о повреждённом комплекте | Заново распакуйте полный установочный ZIP; не переносите отдельно только `Install.cmd`. |
| Ссылка не загружается | Проверьте доступность подписки; поддерживаются HTTPS, VLESS/Hysteria 2 и Base64. JSON/Clash-конфигурации не поддерживаются. |

## Обновление и удаление

Перед обновлением отключите VPN и выключите расширение в `chrome://extensions`. Запустите новый `Install.cmd`, затем включите/перезагрузите расширение. ID и путь расширения постоянные. Старые версии помощника остаются до удаления, чтобы не удалять используемые файлы.

Для удаления отключите VPN, удалите расширение в Chrome и запустите «Chrome VPN for CottonClub» в списке установленных приложений Windows либо `C:\Program Files\Chrome VPN for CottonClub\Uninstall.cmd`. Помощник, ядра, его регистрация и ярлыки удаляются. Общий HWID `%LOCALAPPDATA%\ZXC-Desktop\device-id.txt` и пользовательские данные сохраняются. Подписка хранится в локальном хранилище расширения без дополнительного шифрования приложения.

Если исходная админская версия уже установлена, сначала отключите VPN и удалите её помощник и расширение, затем установите CottonClub. Исходные файлы проекта в соседней папке не изменяются.

## Сборка из исходников

Нужен Python 3.11 x64 с pip. Из этой папки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Build.ps1
```

Сборка автоматически создаёт окружение, устанавливает фиксированные зависимости, скачивает Xray/sing-box с проверкой опубликованных SHA-256 и собирает только помощник с расширением. `-SkipDownload` использует существующий `src/bin/`. Готовый ZIP содержит проверяемый список SHA-256 файлов (защита от повреждения, не цифровая подпись издателя). Установщик и помощник не подписаны сертификатом издателя.

В этой версии проверка интернет-соединения исправлена на SOCKS5 с удалённым DNS (`socks5h`) для совместимости с обоими ядрами. В комплект включён PySocks.

Ограничения: VPN действует на обычные окна профиля Chrome, не на всю Windows; инкогнито не поддерживается. После перезапуска браузера подключитесь заново. Проверка внешнего адреса использует `api.ipify.org` через VPN. При падении помощника прокси остаётся включённым до переподключения или явного отключения. Удаление/выключение расширения снимает его настройки.

Документация Chrome: https://support.google.com/chrome/a/answer/7532015 и https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging.

## Проверки и структура

После сборки:

```powershell
src/.venv/Scripts/python.exe -B tests/run.py
node --test tests/extension.test.cjs
src/.venv/Scripts/python.exe -B tests/package_smoke.py
```

Для JavaScript-тестов нужен Node.js 22+. Проверка комплекта не устанавливает помощник и не изменяет настройки Chrome. Границы выполненных проверок описаны в [VERIFICATION.md](VERIFICATION.md).

- `extension/` — интерфейс и управление настройками Chrome.
- `src/` — помощник, разбор подписок и запуск ядер.
- `src/routing/` — встроенные правила и сведения об их происхождении.
- `Build.ps1` — сборка готового комплекта.
- `Install.*`, `Uninstall.*`, `Launch.*` — установка, удаление и открытие настройки.
- `tests/` — автоматические проверки.
